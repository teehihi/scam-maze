- Not used by the game yet. When a model is used, add it to `apps/game/src/config/credits.ts`
  with its source and license, and optimize it into `public/` (for example with `scripts/optimize-environment.cjs`); keep this source file in `assets-src/`, which is not shipped in the build
  (each file is about 25 MB).
- The models depict a real-world phone product. In-game, do not show real brand names or logos.
